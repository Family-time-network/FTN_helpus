# Family Time Network - FTN_helpus

## Organization Overview

**Family Time Network (FTN)** is a global digital infrastructure and cybersecurity organization focused on secure internet resource management, domain governance, and technical standards compliance.

- **Mission:** Provide secure, transparent, and standards-based digital services
- **Vision:** Promote trust, internet stability, and responsible digital governance worldwide

## Technical Standards & Protocols

### Supported Standards
- **DNS Security:** DNSSEC
- **Transport Security:** TLS 1.2 and above
- **Routing Security:** RPKI best practices
- **Email Security:** SPF, DKIM, DMARC
- **Web Security:** HSTS, CSP, X-Frame-Options
- **Authentication:** MFA and strong access controls

### Security Principles
- Least-privilege access control
- Encryption in transit and at rest
- Regular security review and auditing
- Standards-based technical governance
- Industry best practices for internet resilience
